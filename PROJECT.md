# VideoSorter-by-Jair-Lima

## Descrição
Move vídeos que foram parar na pasta de imagens para a pasta de vídeos, preservando datas e subpastas.

## Stack
Python 3.10+, apenas biblioteca padrão.

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python videosorter.py`
